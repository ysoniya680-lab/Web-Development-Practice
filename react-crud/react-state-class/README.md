# React State Practice

This folder contains React practice exercises focused on state management using the `useState` Hook.

## Topics Practiced
- React functional components
- `useState` Hook
- Updating state
- Handling button click events
- Counter App
- Like Button

## Run the Project

```bash
npm install
npm run dev
```

## Learning Notes
This project is used to practice concepts covered in class. Some initial code was referenced from Saloni Kashyap's React learning repository, and the exercises will be further practiced and modified as part of my learning.
